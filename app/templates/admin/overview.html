Device Links

These links are secret - anyone who has one can check customers in (Kiosk) or see who's waiting (TV Display) at that location, no login required. Set one as the home page / bookmark on that location's tablet or TV. If a link ever leaks, regenerate it and update the device.

To run a kiosk full-screen like an app, open its link on the tablet, then use the browser's Add to Home Screen (Safari's Share menu, or Chrome's ⋮ menu) and open it from the new icon. After regenerating a kiosk link, delete that icon and add it again from the new link.
